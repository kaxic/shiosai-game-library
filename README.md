## Windowsで遊ぶ

ZIPをすべて展開し、`潮彩ゲーム棚.exe` を開きます。A〜Fまたは上下キーで選び、Enterで起動できます。ゲームはオフラインで遊べます。

## ホームを編集する

作品のリンクとタイトルは `docs/index.html`、見た目は `docs/style.css`、表紙は `docs/assets/` にあります。各ゲームのシーンやルールは上の各Unityプロジェクトで編集できます。
